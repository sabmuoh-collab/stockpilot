STOCKPILOT — FOUNDATION BUILD (VERSION 0.1)

WHAT THIS BUILD INCLUDES
- Mobile-first StockPilot interface
- Dashboard and navigation
- Stock, sales, customers, purchases, reports and More sections
- Local IndexedDB database foundation
- Product and customer list placeholders
- PWA manifest and service worker foundation

IMPORTANT
This is the foundation build, not the complete inventory system yet.
Product entry, customer forms, sales, credit accounts, payments, purchases,
reports, and backup/restore will be implemented in later stages.

HOW TO PUBLISH WITH GITHUB PAGES FROM YOUR IPHONE
1. Download and unzip this project.
2. Sign in at https://github.com
3. Create a new public repository named stockpilot.
4. Upload the CONTENTS of this folder (index.html, style.css, app.js,
   manifest.webmanifest, sw.js, icons folder) to the repository root.
5. In repository Settings > Pages, select Deploy from a branch.
6. Select main branch and /(root), then Save.
7. Wait for the published website link.
8. Open the link in Safari and use Share > Add to Home Screen.

DATA WARNING
This build uses local browser storage. Do not clear Safari website data for
the published site. Backup/restore is not implemented yet. Do not enter
critical business records until backup/restore is available.
